# Veritas

Calculadora de tabela verdade e simulador de circuitos digitais — 100% no navegador.

## Stack

- React + Vite + TypeScript
- Tailwind CSS
- Motor lógico próprio (Lexer → Parser → AST)

## Desenvolvimento

```bash
npm install
npm run dev
```
