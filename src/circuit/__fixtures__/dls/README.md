Dois chips reais exportados do Digital Logic Sim, copiados do projeto UMBRA LIMA
ALFA sem edição nenhuma.

Servem para o teste do importador rodar sobre o arquivo como ele sai do DLS —
com os campos que o Veritas ignora, os pontos intermediários dos fios e a
numeração de pinos original — em vez de sobre uma amostra escrita à mão, que
concordaria com o importador por construção.

O `XOR` usa o `NOT`, que usa o `NAND`: é uma hierarquia de verdade, de três
níveis, para conferir a ordem de dependência e a referência entre chips.
